FunctionDeclarations — defined inputs, defined outputs.

There is a rule about what appears here: a project earns a card only when it has a publicly verifiable artifact. A public repo, a published package, a live site, or a written document. Everything else is written up and waiting on its repo to open.

That's deliberate. An unlinkable project card invites a click that goes nowhere, and reads weaker than not being there at all. The registry behind this page holds considerably more than four entries; the rest are one flag away.
